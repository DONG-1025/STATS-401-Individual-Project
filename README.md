# Visualization Critique and Redesign

A course project for **Data Visualization**, focused on critically evaluating an existing public health visualization and rebuilding an improved version with **D3.js**.

---

## Project Overview

This project selects an existing data visualization, analyzes its intended message, audience, and tasks, identifies its design strengths and weaknesses, and proposes a redesigned version implemented in D3.js. The goal is to demonstrate that effective visualization goes beyond producing a technically correct chart — it requires clarity, honesty, and suitability for the intended task.

---

## Selected Visualization

**CalCORVID (California Clustering for Operational Real-time Visualization of Infectious Diseases)**

- **Source:** California Department of Public Health (CDPH) Modeling Team
- **Published in:** CSTE Stories from the Field; *BMC Public Health*
- **Original format:** RShiny dashboard
- **Data:** COVID-19 test positivity data aggregated to census tract level in California (September 2021 – February 2022), integrated with the Social Vulnerability Index (SVI)
- **Purpose:** Visualize spatiotemporal disease clusters detected by SaTScan to support public health surveillance and intervention planning

**Links:**
